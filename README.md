# QuickNotes

QuickNotes is a simple note-taking web application built with HTML, CSS and JavaScript. It allows users to create, organise, search and delete notes while keeping their notes saved in the browser using localStorage.

## Features

- Add notes with Personal, Work or Study categories
- Validate notes so they are not empty or longer than 200 characters
- Display notes as styled cards
- Delete individual notes
- Search notes as you type
- Show the total number of notes
- Save notes in localStorage so they survive page refreshes
- Responsive layout for smaller screens

## How to run the project locally

1. Clone or download this repository.
2. Open the `quicknotes-app` folder in VS Code.
3. Open `index.html` using VS Code Live Server, or open the file directly in a browser.
4. Add, search and delete notes to test the application.
